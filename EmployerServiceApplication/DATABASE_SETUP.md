# Oracle Database Setup

This application is configured to use Oracle Database through the `EMPLOYEE_APP` schema.

## 1. Create the Oracle user

Connect to Oracle SQL Developer as `system`, then run:

```sql
CREATE USER EMPLOYEE_APP IDENTIFIED BY change_me;

GRANT CONNECT, RESOURCE TO EMPLOYEE_APP;
GRANT CREATE SESSION TO EMPLOYEE_APP;
GRANT CREATE TABLE TO EMPLOYEE_APP;
GRANT CREATE SEQUENCE TO EMPLOYEE_APP;
GRANT CREATE PROCEDURE TO EMPLOYEE_APP;
GRANT UNLIMITED TABLESPACE TO EMPLOYEE_APP;
```

Update `change_me` to the password you want to use.

The same script is available at `database/01_create_employee_app_user.sql`.

## 2. Configure the application

The Oracle connection is configured in `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:oracle:thin:@localhost:1521/FREEPDB1
spring.datasource.username=EMPLOYEE_APP
spring.datasource.password=change_me
```

Adjust the host, port, service name, username, and password for your Oracle environment.

Common local Oracle JDBC URLs:

```properties
spring.datasource.url=jdbc:oracle:thin:@localhost:1521/FREEPDB1
spring.datasource.url=jdbc:oracle:thin:@localhost:1521/XEPDB1
spring.datasource.url=jdbc:oracle:thin:@localhost:1521/ORCLPDB1
```

## 3. Optional manual table creation

The app currently uses Hibernate with `spring.jpa.hibernate.ddl-auto=update`, so Hibernate can create or update the table automatically.

For the PL/SQL flow, create the table and procedure manually. Connect to SQL Developer as `EMPLOYEE_APP`, then run `database/02_create_employee_schema.sql`.

The table created by that script is:

```sql
CREATE TABLE EMPLOYEES (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NAME VARCHAR2(255) NOT NULL,
    EMPLOYEE_ID VARCHAR2(255) NOT NULL UNIQUE,
    EMPLOYEE_ROLE VARCHAR2(255) NOT NULL,
    EMAIL_ADDRESS VARCHAR2(255) NOT NULL UNIQUE,
    PHONE_NUMBER VARCHAR2(255) NOT NULL
);
```

The procedure created by that script is `SAVE_EMPLOYEE`. Spring Boot calls it when you use:

```text
POST http://localhost:8080/employees/pull-from-api
```

After manually creating tables, consider changing:

```properties
spring.jpa.hibernate.ddl-auto=validate
```

## 4. Configure the external API

Update this property with the real API URL:

```properties
external.employee-api.url=https://example.com/api/employees
```

The app currently expects the API response to be a JSON array:

```json
[
  {
    "employeeId": "E001",
    "name": "John Smith",
    "employeeRole": "Developer",
    "emailAddress": "john@example.com",
    "phoneNumber": "1234567890"
  }
]
```

## 5. Run the application

```powershell
.\mvnw spring-boot:run
```

Then trigger the API pull:

```powershell
curl -X POST http://localhost:8080/employees/pull-from-api
```
